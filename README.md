# Project Name : Excel-Tableau-Commerce-Analytics
Project objective : This project cleans and filters raw e-commerce data using Microsoft Excel. It then presents key business insights, performance metrics, and sales trends through interactive executive-level dashboards developed in both Excel and Tableau for clear visualization.

# Dataset used
- <a href="https://github.com/krithikraja146-beep/Excel-Tableau-Commerce-Analytics/blob/main/Retail%20Analysis%20Working.xlsb">Dataset</a>

# Tools Used
Excel: Cleaned raw data, filtered excess rows, calculated RFM metrics (Recency, Frequency, Monetary value), and built initial dashboards.
Tableau: Created interactive executive sales and RFM customer cohort dashboards.
Project Workflow
Clean & Filter Data (Excel): Removed unnecessary rows, formatted data, and handled missing values.
Perform RFM & Cohort Analysis (Tableau):
Recency: Days since last purchase.
Frequency: Total number of orders.
Monetary: Total spend per customer.
Segmented customers into cohorts (e.g., Champions, Loyal, At-Risk) to analyze purchasing behavior over time.
Build Baseline Dashboard (Excel): Created initial KPI charts, Pivot Tables, and Slicers.
Build Advanced Dashboard (Tableau): Connected the cleaned dataset to build dynamic executive sales views and interactive RFM cohort visualizations.
