# Project Name : Excel-Tableau-ECommerce-Analytics
Project objective : This project cleans and filters raw e-commerce data using Microsoft Excel. It then presents key business insights, performance metrics, and sales trends through interactive executive-level dashboards developed in both Excel and Tableau for clear visualization.

# Dataset used
- <a href="https://github.com/krithikraja146-beep/Excel-Tableau-Commerce-Analytics/blob/main/Retail%20Analysis%20Working.xlsb">Dataset</a>

# Tools Used
Excel: Cleaned raw data, filtered excess rows, calculated RFM metrics (Recency, Frequency, Monetary value), and built initial dashboards.

Tableau: Created interactive executive sales and RFM customer cohort dashboards.

Project Workflow

Clean & Filter Data (Excel): Removed unnecessary rows, formatted data, and handled missing values.

Perform RFM & Cohort Analysis (Tableau):

Recency: Days since last purchase.

Frequency: Total number of orders.

Monetary: Total spend per customer.

Segmented customers into cohorts (e.g., Champions, Loyal, At-Risk) to analyze purchasing behavior over time.

Build Baseline Dashboard (Excel): Created initial KPI charts, Pivot Tables, and Slicers.

Build Advanced Dashboard (Tableau): Connected the cleaned dataset to build dynamic executive sales views and interactive RFM cohort visualizations.

# Questions (KPI)

1. Total Revenue & Growth: What is our total revenue, and how is it growing month-over-month?
2. Profitability: Which product categories and sub-categories are generating the highest profit margins?
3. Average Order Value (AOV): What is the average dollar amount spent per transaction across different customer segments?
4. Geographic Distribution: Which geographic regions and cities generate the highest sales volume and order density?
5. Order Volume & Fulfillment: What is the total volume of orders processed, and what is the return/cancellation rate?
6. Top Performing Products: What are the top 10 best-selling products by total revenue and units sold?

7. RFM Customer Segmentation: Who are our highest-value customers ("Champions") versus "At-Risk" buyers based on their Recency, Frequency, and Monetary scores?

8. Cohort Retention & Lifetime Value: What percentage of customers from each monthly cohort return to make repeat purchases, and how does their spending evolve over time?

Project Process

2. RFM & Cohort Analysis

   Calculated Recency, Frequency, and Monetary scores in Excel to segment customers (e.g., Champions, At-Risk) and group them into monthly cohorts.

3. Baseline Dashboard (Excel)

   Built summary Pivot Tables, basic charts, and interactive Slicers for quick filtering.

4. Advanced Dashboard (Tableau)

   Connected the cleaned dataset to Tableau to create interactive executive views, regional heatmaps, and RFM cohort retention matrice.
